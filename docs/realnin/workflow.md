# 商城管理端协作流程

日期：2026-10-31｜状态：本地规划草案。本文是拟采用的工作流，不表示页面、远程Project、PR、CI或真实接口已完成。

## 范围

当前实现范围仅为商品、商城类目、配送、城市四模块的管理端前端、mock和接口契约。登录、订单、支付、退款、举报和闲置通过共享契约对接，不顺手实现其他模块。本轮不开发后端或部署云资源。

## 实施顺序

页面与独立数据层 → 同契约的mock正常/失败场景 → 接口文档 → 与移动端规则对齐 → 数据库方案评审 → 后续Go实现和真实联调。

Vue3网页管理端与uni-app移动端分别组织。View只负责绑定和交互，请求、校验、解析、金额转换在数据层；表单双向绑定本地编辑状态，不代表服务器已保存。所有手写函数/方法保留中英双语注释。Ant Design Vue可作为Vue组件库候选；Ant Design Pro是React方案，不能混作同一个脚手架。依赖与版本须在实际初始化时固定。

建议一个仓库保留四个应用边界：

```text
frontend/admin/     Vue3管理端
frontend/mobile/    uni-app移动端
backend/admin/      Go管理入口
backend/mobile/     Go顾客入口
```

后续后端用共享domain和契约复用库存、商品、配送与状态规则，避免两套业务真相；四目录不等于四个微服务或四套数据库。Go遵守Controller/Service/DAO分层。认证入口和权限边界分别验证。

## Story与PR

一条可独立验收的Story对应一个Issue、一条分支、一个PR。Issue记录owner、范围/排除项、依赖、契约版本、验收条件及证据；分支从约定基线创建，关联Issue，不直接修改主分支。

| Project状态建议 | 条件 |
|---|---|
| Todo | 范围、owner、验收草案齐全 |
| InProgress | 已认领并关联分支，关键依赖就绪或有明确替身 |
| InReview | PR可审查，证据齐，检查结果已记录 |
| Done | PR合并且当前阶段验收通过，证据归档 |

状态字段和自动化须真实配置后验证，不把Issue关闭等同于已部署。Done保护已验收范围；修复和需求变更新Issue，链接原Story，列回归场景，走新分支和PR，不随意重写已完成模块。

## 共享边界

共享壳提供认证状态、路由/导航、统一请求错误、上传与公共数据接口。商城模块只挂载自身页面并调用约定接口。共享壳未就绪时可用明确标记的隔离演示壳和mock，不创建第二套真实登录或长期保留的重复公共实现。跨模块改动先列影响并经owner评审。

金额契约统一整数分；账面、锁定、可售由服务端返回，页面不自行推导权威可售。类目有上架商品引用时拒绝删除；城市方式、可送区与时段联动；配置变化只影响新订单。保存冲突、网络失败、无权限等结果不显示伪成功。业务删除遵循软删约定。

## DoR与DoD

DoR：范围属于四模块；来源章节、页面和可观察验收明确；单位、空值、枚举与权限依赖清楚；接口已定或明确标草案；正常与失败mock可用；共享文件owner清楚。

DoD：按当前阶段验收。规划Story交付可审查设计/契约；前端mock Story需可运行、关键场景可重现、必要检查和review通过、截图对应版本。真实API未接入应写“前端mock完成”，不可写“生产功能完成”。真实集成另记环境与结果。

PR审查范围、分层、双语注释、金额/失败语义、共享影响、秘密与个人资料。建议CI覆盖格式/静态检查、类型、构建、必要适配/交互测试及依赖/秘密检查；未落地或未执行的检查写未执行，不拿空源码扫描当应用合规。

证据记录提交、路由、环境、mock/真实API、契约版本、步骤、预期/实际、脱敏截图。重点回归：库存低于锁定被拒；空/重名/引用类目删除被拒；城市改线下未配区；时段停用与保留；配置不改历史订单。契约字段、单位或错误语义变化写版本记录，同步样例和截图。

## 发布与资料边界

本地生成、Git提交、远程PR、主分支合并、真实环境验收分别报告。公开仓库只放允许公开的代码、规范摘要和脱敏样例，不放原始会议转写、账号凭据、真实顾客数据或私人附件路径。部署、DNS、云资源、证书、真实第三方调用需要单独范围和证据；本文件不执行这些动作。Nginx可按域名/SNI共享80/443，额外管理端端口不是单机的必然要求。
