# 管理端与移动端体验

先读 [开发规范](../../../engineering/DEVELOPMENT_STANDARDS.md)，核对真实需求、原型和当前框架。移动端采用 Uniapp；本次管理端建议 Vue 3，最终框架和组件库实施前确认，不把 Ant Design Pro 候选自动当作已选 React。

- View 与数据层分文件。请求、响应状态/结构校验、字段映射及业务转换在数据层完成，View 接收明确的响应式状态与命名事件入口。
- 表单用本地可编辑状态双向绑定，命名方法校验并提交；双向绑定不代表自动同步服务器或绕过数据层修改原始响应。
- Uniapp 统一封装 uni.request；独立管理端使用所选浏览器平台的统一请求封装。统一契约与错误语义，保留超时、取消和安全重试边界。
- 分开加载、空态、失败、真实零值和缺值；核对权限、可访问性、移动适配及过期响应不覆盖新状态。
- 所有手写函数和方法写中英双语说明，核心处理用命名方法，不藏进长回调。

运行 [harness](../../../engineering/harness/README.md)。按实际目标验证证书、域名、跨域/Cookie、平台权限和构建；原生 HTML/JS 原型与静态扫描不证明 Vue/Uniapp 应用已完成或可上线。
